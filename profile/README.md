# IQ Bible

**Bible knowledge infrastructure for AI, study & faith apps.**

IQ Bible is a company and ministry building modern Bible technology. The IQ Bible API v2 is the knowledge layer behind intelligent Bible applications — Scripture across 1,400+ translations and 1,000+ languages, original Hebrew and Greek down to the word, Strong's lexicons, morphology, commentary, biblical geography, chapter audio, and a navigable cross-reference graph in one modern REST API. AI Context endpoints assemble Scripture, cross-references, commentary, and Strong's glosses into one prompt-ready call.

- **API landing page:** https://api.iqbible.com
- **Developer portal & docs:** https://developer.iqbible.com
- **Free tier:** 50,000 requests/month, no card required
