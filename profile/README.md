# IQ Bible

**Bible knowledge infrastructure for AI, study & faith apps.**

IQ Bible is a company and ministry building modern Bible technology. **IQ Bible API v2** is the knowledge layer behind intelligent Bible applications — Scripture across 1,400+ translations and 1,000+ languages, original Hebrew and Greek down to the word, Strong's lexicons, morphology, commentary, biblical geography, chapter audio, and a navigable cross-reference graph in one modern REST API. AI Context endpoints assemble Scripture, cross-references, commentary, and Strong's glosses into one prompt-ready call.

### IQ Bible API v1 (legacy)

v1 is the original API, available through [RapidAPI](https://rapidapi.com/vibrantmiami/api/iq-bible/). It's stable and still supported for existing integrations, but receives **no new features or endpoints**. New projects should use **v2** — [api.iqbible.com](https://api.iqbible.com).
